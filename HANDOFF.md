# Передача калькулятора заказных тортов Марине

## С чего начать в новом Codex

Марина — шеф-кондитер и владелец технологических решений. Откройте вместе с ней эту папку как проект, прочитайте этот файл и запустите калькулятор. Покажите ей текущий расчёт лимонно-макового на 2,5 кг из контрольного примера ниже. Затем обсудите один реальный заказ, для которого витринную техкарту надо дополнить поправкой. На этом примере договоритесь, где хранить поправку, к чему её применять и как она должна выглядеть в заданиях цеху и в накладной. После разговора продолжайте с существующим приложением.

Фраза для начала нового чата:

> Прочитай HANDOFF.md в корне. Запусти текущий калькулятор и проверь контрольный лимонно-маковый торт. Затем обсуди со мной надстройку над витринными техкартами для заказных тортов. Начнём с одного моего примера, уточним, что именно меняется относительно ТТК, и внесём это в калькулятор.

## Как перенести и запустить

Передайте этот файл и папки `cake-calculator/` и `files/` рядом. Сохраните структуру папок, чтобы ссылки на оригиналы открывались из калькулятора. Переписка `messages.md` и `messages.json` для запуска не требуется. Откройте в Codex общую папку, которая содержит обе папки и этот файл.

Из этой общей папки запустите:

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

На Windows команда может называться `py -m http.server 8765 --bind 127.0.0.1`. Откройте [калькулятор](http://127.0.0.1:8765/cake-calculator/). Для работы достаточно Python и браузера. Приложение написано на HTML, CSS и JavaScript без сборки, серверной базы и ключей API.

**После переноса файлов будут доступны встроенные рецептуры и два исходных примера из истории.** Внесённые позднее через интерфейс рецептуры, черновики, фактические заказы и вложения хранятся в профиле старого браузера. Приложение пока не экспортирует их единым пакетом. Если среди них есть рабочие записи, сначала выясните, какие нужно перенести. Источник хранения привязан к адресу сайта, поэтому на новом компьютере для регулярной работы открывайте один и тот же адрес.

## Задача следующего этапа

ТТК в Tillypad описывают в первую очередь **витринные торты**. Калькулятор нужен для **заказных тортов**, где бывают дополнительные потери, другая толщина, больше крема, отделка, особая форма или запас для цеха. Следующее изменение — сделать надстройку над базовой техкартой. Марина должна иметь возможность задать поправки для заказного торта и видеть, из чего сложился расчёт. Текущие встроенные рецептуры уже смешивают исходные данные и несколько рабочих поправок. При проектировании сначала определите, какие из них относятся к исходной ТТК, какие пришли из уточнений Марины и какие получены расчётным путём.

Для первого разговора с Мариной подойдут три вопроса:

1. Возьмём один заказной торт. Какие позиции по сравнению с витринной ТТК у него меняются? Сколько было по ТТК и сколько вы фактически заложили? Подойдут и случаи, когда норма уменьшается.
2. Для каждой поправки куда идут дополнительные граммы: входят в целевой вес готового торта, остаются запасом после замеса или теряются при обрезке и сборке? Какую величину Марина обычно знает заранее: коэффициент, дополнительные граммы, толщину, размер или число слоёв?
3. Где сохранить правило: только в этом заказе, как типовой вариант конкретной рецептуры или для нескольких рецептур? Если есть и типовая норма, и разовая поправка, какая имеет приоритет?

Особенно важно различать массу **в готовом торте**, **выход полуфабриката** и **закладку сырья с запасом**. Например, лишний выпеченный корж входит в задание пекарю. В плановом списании на торт учитывается только использованная масса, а фактический расход можно внести в накладной. Дополнительный слой начинки, наоборот, входит в целевой вес. Коэффициент запаса для цеха поэтому нельзя автоматически применять к весу готового торта.

Рабочий вариант для обсуждения — хранить исходную ТТК, поправку для заказного исполнения и параметры конкретного черновика отдельно. В расчёте показывать базовую норму, применённую поправку и итог, а подтверждённые значения сохранять вместе с черновиком. Формат правил и их приоритет пока открыты. Начните с одного подтверждённого случая, прежде чем вводить общие коэффициенты для всех тортов.

## Что уже работает

- Три режима: подобрать размеры по целевому весу, посчитать вес по заданным размерам, пересчитать только по весу. Геометрия рассчитана на один ярус. Поддерживаются круг, овал и прямоугольник. Для режимов по форме нужен компонент с эталонной формой, закладкой и выходом. Толщина `×1` означает исходную толщину.
- Целевой вес задаётся **без подложки**. Подложка нужна только для записи фактического взвешивания. Крем для обтяжки и клубника включаются по умолчанию там, где задана норма. Их можно выключить. В режиме по весу оставшиеся компоненты перераспределяются под тот же целевой вес.
- Задания для пекаря и кондитера показывают сырьё. Накладная к списанию показывает полуфабрикаты и покупные позиции отдельными строками, например свежую клубнику. Фактический расход можно ввести отдельно. CSV можно скачать. PDF сохраняется через диалог печати браузера. Печатная форма компактная, с шапкой и таблицей.
- Параметры заказа сохраняются при вводе, после расчёта сохраняется и его результат. Черновики открываются из истории. Кнопка «Записать результат заказа» сохраняет взвешивание, расход, заметки и при наличии фото, затем переносит заказ в готовые.
- Техкарты редактируются в браузере. Сырьё можно ввести вручную, вставить двумя столбцами из Excel или импортировать из CSV UTF-8 с разделителем «точка с запятой». XLSX, PDF и фото можно прикрепить как оригиналы. Содержимое этих вложений автоматически не разбирается. Интеграции с Tillypad нет. Прежнее поле текстового запроса убрано, ввод идёт через параметры формы.

## От чего отталкиваться в расчётах

### Лимонно-маковый

Марина подтвердила **200 г сливочного крем-чиза на прослойку при Ø18 см**. В стандартной сборке три коржа и две прослойки, то есть 400 г крема внутри. Финишное выравнивание делается **крем-чизом на масле**, у него отдельная рецептура и отдельная строка списания. Для четырёх коржей в расчёте три прослойки. Сливочный крем пересчитывается по площади и числу прослоек.

**Контрольный заказ Марины** — круглый торт на **2,5 кг при Ø20 см**, четыре коржа, обрезь 0%, толщина `×1`, без клубники, с обтяжкой. В текущем приложении режим подбора размера даёт Ø20 см, а режим заданного диаметра показывает 2,500 кг. Результат до округления около 2,5004 кг. Состав приблизительно такой:

| Компонент | В готовый торт |
|---|---:|
| Пан де Жен маковый | 856 г |
| Сироп, лимонный сок и курд вместе | 327 г |
| Сливочный крем-чиз на три прослойки | 741 г |
| Крем-чиз на масле для обтяжки | 576 г |

В прежней версии при тех же параметрах появлялись Ø14,7 см или 4,643 кг при Ø20 см. Все 880 г сливочного крем-чиза из ТТК принимались за норму начинки, затем ещё 625 г на килограмм увеличенной основы добавлялись на обтяжку. Это давало около 1,674 кг крема внутрь и 1,786 кг на обтяжку. Исправленный контрольный пример нужен, чтобы эта ошибка не вернулась после добавления надстройки. Поддерживается обновление известных старых записей рецептуры и пересчёт старого черновика без фактической накладной при открытии. Планы с сохранённым фактом остаются доступны с пометкой о прежней карте.

**Что пока оценено.** Масса крема на масле для Ø20 см получена по разнице между целевыми 2,5 кг и расчётной массой сборки до обтяжки. В коде она представлена ориентиром 467 г на Ø18 см и масштабируется по площади. Это калибровка по одному заказу, а не замер нанесённого крема. Для других высот, толстого покрытия и рюшей нужны данные Марины. Пан де Жен сейчас считается по заданию пекарю из Excel. Состав в Tillypad отличается, рабочую версию ещё нужно подтвердить. В модели Excel на три кольца Ø18 см заложено по 400 г теста, расчётный выход всей партии 1 040 г, по два слоя из одного кольца.

### Медовый

Марина дала эталон одного коржа Ø18 см: **60 г сырого теста и около 30 г готового коржа после штатной обрезки**. Один корж считается одним слоем. Состав из ТТК приведён к порции теста 60 г. Штатная обрезка уже учтена в выходе 30 г. Поле «Дополнительная обрезь» используется для потерь сверх штатных. Например, для трёх коржей Ø18 см при `×1` калькулятор закладывает 180 г теста и ожидает 90 г готовых коржей.

Цветная глазурь 40 г из ТТК пока не включена, так как состава сырья для неё нет. Отдельно уточните, используется ли она в заказных тортах. Нормы клубники и отделки медового предварительные. Коржи 50 × 30 см из истории были частью конкретного заказа. Для нового размера используйте эталон Ø18 см и реальные потери, если корж режется из листа.

### История заказов

Два вложенных примера служат справкой. Двухъярусный лимонно-маковый с сердцем весил **6,3 кг с подложкой**. В записи подложка 0,6 кг, арифметически это 5,7 кг без неё, по оценке Марины около 5,8 кг. Медовый на юбилей весил **8,3 кг с подложкой 0,65 кг**, то есть 7,65 кг без неё. 750 г ягод на нём хватило только на редкую выкладку. Эти наблюдения помогают обсуждать поправки. При сравнении с новым заказом сверяйте форму, отделку и способ взвешивания.

## Что проверить после первой поправки

- Контрольный лимонно-маковый на 2,5 кг проходит в обоих направлениях. В накладной сливочный крем и крем на масле стоят отдельными строками.
- Поправка для заказного торта применяется один раз. Из результата видно, добавила она вес в готовый торт, сырьё на замес или потери. Исходная ТТК открывается с прежними значениями.
- Выключение клубники пересчитывает состав при том же целевом весе в режиме по весу. Изменение запаса на замес само по себе целевой вес не меняет.
- Медовый при Ø18 см использует 60 г теста и примерно 30 г готового коржа на слой. Штатная обрезка не вычитается повторно.
- Черновик открывается после перезагрузки, сохраняет параметры и поправки. Накладная остаётся короткой, а типовые задания и накладная помещаются на один лист A4.
