# Калькулятор тортов

Рабочий репозиторий проекта из архива «Калькультор тортов.zip».

## Запуск

Из корня репозитория:

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

Откройте http://127.0.0.1:8765/cake-calculator/.

## Содержимое

- `cake-calculator/` — исходники приложения и инструкция по работе.
- `files/` — исходные рецептуры, фотографии и документы.
- `HANDOFF.md` — описание состояния проекта на момент передачи.
- `messages.md`, `messages.json` — архив предыдущего обсуждения, справочный материал.
- `sites/` — сохранённая копия версии для размещения из исходного архива.

Исходники и материалы перенесены без изменения. Служебные файлы macOS исключены.
Дальнейшие изменения приложения вносятся в `cake-calculator/`.

Данные заказов и пользовательские рецептуры хранятся в браузере и не входят в Git.
