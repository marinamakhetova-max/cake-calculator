# Калькулятор заказных тортов

Из папки с материалами Марины запустите:

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

Откройте [калькулятор](http://127.0.0.1:8765/cake-calculator/). Техкарты, черновики, история и вложения хранятся в профиле браузера по этому адресу.

## Расчёт заказа

- **По весу с подбором размеров**. Укажите целевой вес, форму и число слоёв. Для овала и прямоугольника укажите отношение длины к ширине. Размеры округляются до 0,1 см.
- **По заданным размерам**. Укажите диаметр или ширину и длину. Выход рассчитывается по площади эталонной формы, числу слоёв и поправкам на толщину и обрезь.
- **Только по весу**. Сырьё и полуфабрикаты пересчитываются по выходу без подбора формы. Когда в техкарте нет замеров эталонной формы, доступен этот режим.

Подложка в расчёте не учитывается. Её можно указать при записи фактического взвешивания. Крем для обтяжки и клубника по умолчанию включены у рецептур, для которых заданы нормы. При отключении отделки в режиме по весу освобождённая масса распределяется между основой, начинкой и оставшейся отделкой. При заданных размерах меняется расчётный вес торта.

По весу нормы отделки выражены в граммах на килограмм основы с начинкой. В расчётах лимонно-макового по форме применяется норма на Ø18 см: по 200 г сливочного крем-чиза на прослойку и ориентир 467 г крем-чиза на масле на обтяжку. Прослойка и обтяжка пересчитываются по площади, а для прослойки учитывается число промежутков между коржами. Нормы ягод и отделки медового пока ориентировочные. В техкарте можно поправить нормы и добавить именованный декор.

## Черновики и документы

Параметры сохраняются при вводе. После расчёта сохраняются массы и документы. Черновики доступны в «Истории заказов» и восстанавливаются после перезагрузки. Кнопка «Новый расчёт» начинает отдельный черновик. По кнопке «Записать результат заказа» можно внести фактический вес и перенести черновик в готовые заказы.

Задания для цеха показывают закладку сырья. Накладная показывает полуфабрикаты в массе, которая пошла в торт, и покупные позиции, например свежую клубнику. В ней можно внести фактический расход и скачать CSV. В печатной версии остаются шапка и таблица. Для PDF выберите сохранение в диалоге печати.

## Добавление техкарты

1. В «Техкартах» добавьте рецептуру. Для полуфабриката укажите сырьё, выход всей партии и массу в базовой сборке. Нормы отделки вводятся один раз в рецептуре. Для нормы крема также нужен компонент «Обтяжка».
2. Сырьё можно вписать строками «Название = граммы», вставить двумя столбцами из Excel или загрузить как CSV UTF-8 с разделителем «точка с запятой». Для массы в килограммах выберите «кг» при импорте. Пример строк — `Наименование;Масса, кг` и `Мука;0,240`. В техкарте будет 240 г.
3. Для пересчёта размеров укажите эталонную форму коржей, длину и ширину либо диаметр, число форм в партии, массу теста на одну форму и число слоёв из неё. Сырьё и выход должны соответствовать всей партии. Для отдельного полуфабриката доступна кнопка «Пересчитать полуфабрикат».
4. Оригиналы XLSX, PDF и фото можно прикрепить. Для включения в расчёт перенесите массы из оригинала в поля техкарты.

## Что сверить с Мариной

- **Медовые коржи.** Эталон Ø18 см, 60 г сырого теста, около 30 г выход после штатной обрезки на один слой. Состав сырья из ТТК приведён к порции 60 г. В поле «Дополнительная обрезь» указываются только потери сверх штатных.
- **Лимонно-маковый.** Сливочный крем-чиз идёт в прослойку из расчёта 200 г на Ø18 см. Для обтяжки используется крем-чиз на масле. В контрольном заказе на 2,5 кг при Ø20 см, четырёх коржах и без клубники на обтяжку приходится около 576 г по разнице с расчётной массой начинки и коржей. Это оценка для выравнивания, фактическая закладка зависит от высоты и толщины покрытия. Рабочую версию Пан де Жен ещё нужно подтвердить. Сейчас сырьё берётся из задания пекарю.
- **Отделка.** Для типовых тортов запишите вес основы до отделки, вес нанесённого крема и массу ягод. Отдельно отмечайте рюши, плотную выкладку или остатки. Если в медовом используется цветная глазурь из ТТК, нужна её раскладка.
- **Высота и потери.** Для точной проверки на нестандартных размерах нужны высота готового коржа и вес после охлаждения и обрезки. Геометрия сейчас рассчитана для одного яруса по равной толщине или по заданной поправке.
